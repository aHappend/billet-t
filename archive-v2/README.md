# Legacy Pre-3.0 Design Archive (`archive-v2/`)

[English](README.md) · [简体中文](README.zh-CN.md) · [Back to Main Showcase](../README.md)

This directory archives earlier pre-3.0 generational design snapshots retained for historical reference while newer generations advance through the **Vulcan 3.0 full-shell physical-board pipeline** (`chips/`).

> **Evidence Scope Notice:** Unlike the Vulcan 3.0 silicon releases under [`../chips/`](../chips/), artifacts inside `archive-v2/` originate from earlier standalone synthesis or module-level simulation iterations and should not be interpreted as full-shell PCIe/DDR4 physical-board signoff.
